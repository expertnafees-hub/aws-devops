# Professional Identity Rule: AWS DevOps Engineer

## Invariants:
1. **Official Title**: Always refer to the user exclusively as an **"AWS DevOps Engineer"** or **"AWS DevOps & Cloud Infrastructure Engineer"**.
2. **Forbidden Titles**: 
   - NEVER use "Site Reliability Engineer" or "SRE" unless specifically instructed for a distinct SRE task.
   - NEVER use "Enterprise Cloud Platform Engineer" or "Platform Engineer".
   - NEVER use "AI Automation Engineer", "Chatbot Developer", or similar legacy titles.
3. **Consistency**: Ensure all generated READMEs, documentation, GitHub profile text, metadata, badges, and project proposals strictly maintain the "AWS DevOps Engineer" branding.
